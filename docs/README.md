# HandNotesAI documentation

All project documentation lives in this folder. Each document owns one topic and keeps a decision log, so the reasons behind changes aren't lost.

| Document | What it covers |
| --- | --- |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Full system architecture: stack, folder structure, routes, rendering/caching and data flow, auth, AI pipeline, Vapi voice, state management, the 20 UI engineering decisions (summary), open decisions. Start here. |
| [UI_ENGINEERING.md](UI_ENGINEERING.md) | The 20 UI engineering patterns in detail: what, where, how (Next 16 + React 19), rules and done-criteria for each. |
| [DESIGN.md](DESIGN.md) | Design system: colors, typography, spacing, components (navbar, hero, note and book cards), brand assets and design decisions. Source of truth for tokens: [`app/globals.css`](../app/globals.css). |
| [TYPESCRIPT.md](TYPESCRIPT.md) | Type-safe TypeScript: the `types/` folder, interface vs type rules, discriminated unions, `as const` + `satisfies`, typing props and data, and the lint and compiler rules that enforce them. |
| [SECURITY.md](SECURITY.md) | Security policy: reporting vulnerabilities, the automated Claude security review on pull requests, secrets handling and security rules for contributors. |

## Adding a document

1. Create `docs/<TOPIC>.md` in UPPERCASE, matching the existing files (for example `ARCHITECTURE.md`, `API.md`, `DEPLOYMENT.md`, `DATABASE.md`).
2. Start with a one-paragraph summary of what the document covers.
3. Link to code with paths relative to this folder (for example `../app/page.tsx`).
4. End with a **Decision log** table (`Date | Decision | Reason`), newest first.
5. Add a row to the table above.
